# hister-gospel

Aplicativo HTML5 estático para o jogo Hister Gospel.

## Como usar

1. Abra `index.html` no navegador (ou publique no GitHub Pages).
2. Toque em **Iniciar câmera** e permita o acesso à câmera traseira.
3. Aponte para um QR Code com link do YouTube Music (ou ID de vídeo do YouTube).
4. A música será preparada para abrir; se o navegador bloquear abertura automática, toque em **Abrir música**.
