# hister-gospel

Aplicativo HTML5 estático para o jogo Hister Gospel.

## Como usar

1. Abra `index.html` no navegador (ou publique no GitHub Pages).
2. Para gerar QR codes assinados, cole um link do YouTube Music (lista ou música) no campo de geração e toque em **Gerar QR codes**.
3. Para ler um QR, toque em **Iniciar câmera** e permita o acesso à câmera traseira.
4. Aponte para um QR Code com link do YouTube Music, ID de vídeo ou QR assinado pelo app.
5. Toque em **Abrir música** para iniciar a reprodução em segundo plano no player incorporado.
